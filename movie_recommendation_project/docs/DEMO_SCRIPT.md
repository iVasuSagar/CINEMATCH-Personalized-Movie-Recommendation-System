# 2-minute demo script

**Opening (20 seconds):**
“CineMatch is a personalized movie recommendation prototype. It uses collaborative filtering to recommend unseen movies based on rating patterns from similar users.”

**Show the overview (20 seconds):**
“Here are the catalog size, number of ratings, number of users, and average rating. This is a small synthetic dataset so the demo works offline.”

**Show a user’s rating history (20 seconds):**
“I select a demo user and show their ratings. These preferences are the starting point for finding similar users.”

**Generate recommendations (35 seconds):**
“I click Generate recommendations. The system builds user rating vectors, calculates cosine similarity, estimates scores for movies this user has not rated, and ranks the results.”

**Explain limitations (15 seconds):**
“This prototype demonstrates the algorithm, but a real deployment needs a larger real dataset, train/test evaluation, better handling of missing ratings, and persistent user accounts.”

**Close (10 seconds):**
“The main learning outcome is how a machine-learning recommendation method can be connected to an interactive application.”
